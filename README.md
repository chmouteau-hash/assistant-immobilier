# Assistant immobilier et travaux

Projet privé de Christophe pour suivre son projet immobilier, de la recherche d’un bien à la clôture des travaux.

## Essayer la démonstration locale (0.1)

1. Dans GitHub, cliquez sur **Code → Open with GitHub Desktop** et clonez ce dépôt sur votre PC. Un téléchargement ZIP est également possible, mais ne facilite pas les mises à jour.
2. Dans le dossier copié sur le PC, ouvrez **index.html** avec Chrome ou Edge (double-clic). Le fichier n’a pas besoin d’être publié comme site Web.
3. Créez un dossier. Vous pouvez choisir directement l’étape « Réaliser » pour une chambre ou parcourir toutes les étapes pour un projet immobilier.
4. Ajoutez des biens et scénarios, puis des vérifications, idées, montants, tâches, éléments de clôture et retours. La page d’accueil affiche les tâches et quelques repères budgétaires.
5. Cliquez régulièrement sur **Sauvegarder le dossier** et conservez le fichier JSON dans un emplacement privé. **Restaurer une sauvegarde** remplace les données présentes dans ce navigateur.
6. Pour une remontée, utilisez **Faire un retour → Relire / exporter**, retirez les données privées, puis créez une issue GitHub avec le texte relu.

Le code de l’application est dans [index.html](index.html). Ouvrir sa page GitHub affiche le **code source**, pas l’application : il faut ouvrir le fichier copié sur le PC. Les données saisies restent dans le stockage local du navigateur utilisé pour ce fichier ; elles ne sont pas envoyées au dépôt GitHub. L’usage du stockage local avec un fichier ouvert directement peut varier selon le navigateur et son mode de confidentialité : vérifiez l’enregistrement et la restauration avec des données fictives avant d’y saisir un vrai dossier.

## Limites de cette démonstration

Il s’agit d’un premier prototype, pas encore validé par un essai sur le PC de Christophe. Les éléments peuvent être ajoutés et supprimés, mais pas encore modifiés. Les documents sont référencés par leur provenance ou emplacement ; les fichiers originaux ne sont pas intégrés. Les montants sont des sommes simples par nature et scénario, sans calcul financier avancé. Il n’y a pas d’IA, de compte, de synchronisation automatique ni de partage professionnel.
