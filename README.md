# Assistant immobilier et travaux

Projet privé de Christophe pour suivre son propre projet immobilier **de la recherche d’un bien à la clôture des travaux**. La première version doit être utilisable avec une saisie manuelle ; l’IA sera facultative.

## Où commencer

- [Cadrage initial](Assistant_immobilier_cadrage_initial.md) : parcours de A à Z, données, critères de recette et étapes de développement.
- [Issues](../../issues) : fonctions à construire et remontées après les essais.

## Règles de travail

- Un bien peut avoir plusieurs bâtiments et plusieurs scénarios indépendants.
- Les estimations, devis, factures et paiements gardent leurs sources et leur historique.
- Une information inconnue reste inconnue ; une suggestion de l’IA n’est pas une réponse confirmée.
- Les documents du projet personnel restent sur le poste ou dans un espace privé adapté. Ne pas les joindre aux issues GitHub.
- Une remontée décrit le problème, l’écran, le scénario, le résultat attendu et le résultat observé, sans adresse ni donnée personnelle.
